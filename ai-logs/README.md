# AI logs

Save every AI conversation about this project here, and commit the logs with each milestone. Logs are graded on completeness only, never on their content, so don't clean them up.

Name each file `YYYY-MM-DD-topic.md` (or `.json`/`.jsonl` if that's what your tool exports).

How to export:

- **Claude Code:** run `/export` in the session and save the file here.
- **Codex CLI:** sessions are saved under `~/.codex/sessions/`. Copy that session's file here.
- **Copilot Chat (VS Code):** run the command palette's *Chat: Export Chat...*.
- **Web chat (ChatGPT, Claude, Gemini, ...):** export the conversation or copy it into a `.md` file.
