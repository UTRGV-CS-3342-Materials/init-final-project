# Agent instructions

This project is designed by its student developer. The documents in `docs/` are the design, and you follow them.

1. Read `docs/architecture.md` before any change, and follow it. If a request conflicts with it, stop and say so. Do not work around it, and do not edit it unless asked.
2. Any change to the database schema (CREATE, ALTER or DROP, including migration scripts) must update `docs/data.md` in the same change.
3. Every feature you build must map to a feature in `docs/design.md`. If it doesn't, ask first.
4. `reference/` is an earlier class project, kept as an example of the patterns we use. Do not import from it, and do not copy its domain (items, reviews, shopping).
5. Ask before adding any dependency.
